# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |
| Untagged or older source snapshots | No |

## Report a vulnerability privately

Use GitHub's private vulnerability reporting page:

https://github.com/sunweitaosnape-lgtm/deckestra/security/advisories/new

Do not post exploitable details in a public issue. Reports must not include user
documents, uploaded images, real presentations, screenshots, renderings,
credentials, private URLs, or confidential examples. Describe the smallest
synthetic reproduction that demonstrates the issue.

Generated presentations, third-party model providers, and user-controlled
source files remain outside the public source-tree trust boundary.
